# Spec: очистка публичной Git-истории

## Problem statement

Два личных дневника ранее были опубликованы в истории публичного репозитория, хотя уже удалены из текущей ветки.

## Acceptance criteria

- Пути `memory/2026-07-05.md` и `memory/2026-07-06.md` отсутствуют во всей достижимой истории `main`.
- Текущее дерево и серверные addon-файлы не меняются.
- Обновлённая ветка опубликована в GitHub.

## Test plan

1. До переписывания проверить, что оба пути есть в истории.
2. После переписывания проверить, что команда `git log --all -- <path>` не возвращает коммитов.
3. Сверить доступность addon-файлов в GitHub.

## Rollback plan

Перед force-push создать локальную резервную ссылку на исходный `main`. Откат возможен только повторным force-push этой ссылки, что вернёт удалённые данные в публичную историю.
