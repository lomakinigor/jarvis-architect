# Brainstorm - чистая серверная связка

## Проблема

Рабочий Usjarvis на `my-vps` использует базу Jarvis, монтажёр и продюсер, но их чистого и воспроизводимого комплекта в GitHub `lomakinigor` нет.

## Шесть ответов до реализации

1. **Пользовательская проблема.** Нужна установка той же связки на другой сервер без личной памяти, токенов и медиа.
2. **Текущее поведение.** Usjarvis работает на `my-vps`; модули лежат в `/home/agent/packages/` и подключаются как skills.
3. **Желаемое поведение.** Один базовый репозиторий ставит серверного агента и подключает два модуля из двух отдельных репозиториев.
4. **Ограничения.** Нельзя переносить `.env`, сессии, Telegram owner, пользовательские файлы, голос автора, outputs, медиа и зависимости `node_modules`/`.venv`.
5. **Альтернативы.** Хранить всё одним репозиторием проще, но это ломает независимые обновления. Выбран вариант из трёх репозиториев.
6. **Риски.** У продюсера нет найденного Git-донора и в его текущих исходниках есть чужие брендовые настройки. Их нужно нейтрализовать до публикации.
