# Спецификация - чистая серверная связка

## Цель

Собрать три публичных чистых репозитория `lomakinigor`, из которых можно развернуть Usjarvis, монтажёр и продюсер на новом Linux-сервере.

## Пользовательские сценарии

1. Администратор устанавливает базовый Jarvis и запускает скрипт подключения модулей.
2. Скрипт получает монтажёр и продюсер из репозиториев `lomakinigor`, устанавливает их в `/home/agent/packages/` и подключает skills в workspace агента.
3. Пользователь просит смонтировать видео или подготовить контент, и Usjarvis видит соответствующие skills.

## Репозитории

| Репозиторий | Основа | Назначение |
|---|---|---|
| `jarvis-architect` | `Ntmib/jarvis-architect` | База серверного агента и установщик модулей |
| `AutoMontage-Agent` | `Ntmib/AutoMontage-Agent` | Движок монтажёра и чистый skill-адаптер |
| `content-na-vibe` | пакет с `my-vps` | Чистый пакет продюсера и шесть skills |

## Acceptance criteria

- В трёх репозиториях нет `.env`, ключей, сессий, персональных файлов, медиа, outputs, `node_modules` и `.venv`.
- Серверный установщик принимает корень агента и загружает оба модуля из `lomakinigor`.
- Монтажёр подключает skill `avtomontazh`.
- Продюсер подключает шесть skills: `producer-orchestrator`, `trend-hunter`, `video-transcriber`, `scenario-writer`, `presentation-maker`, `lead-magnet-maker`.
- Проверка развёртывания работает на чистом временном каталоге и проверяет структуру, ссылки и отсутствие запрещённых файлов.

## Затронутые компоненты

- `jarvis-architect/server/install-addons.sh` - установка и подключение модулей.
- `jarvis-architect/server/test-module-bundle.sh` - статическая проверка результата.
- `AutoMontage-Agent/.claude/skills/avtomontazh/` - серверный skill-адаптер.
- `content-na-vibe/skills/` - skills продюсера.

## Откат

Установщик не удаляет существующие каталоги. Перед повторной установкой он завершает работу с ошибкой, если путь занят. Откат - удалить только созданные каталоги пакетов и skills нового модуля.
